# Code of conduct

Cairn follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind and patient, especially with people who are new. Criticize
the work, never the person. Harassment and personal attacks aren't allowed in
issues, in pull requests, or anywhere else the project meets.

If someone breaks these rules, report the comment or the account to GitHub
with "Report content" in the comment's menu. The maintainer can hide
comments, lock threads and block accounts.
