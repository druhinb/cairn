# Security

## Reporting a problem

If you find a security problem in Cairn, report it privately. Don't open a
public issue, since that shows the problem to everyone before a fix is out.

1. Go to <https://github.com/druhinb/cairn/security/advisories/new>, or open
   the repository's Security tab and choose "Report a vulnerability".
2. Describe what you found, how to reproduce it, and which version of Cairn you
   used. The app shows its version in Settings.

Only you and the maintainer can see the report, and you'll get a reply there.
When a fix is out, the maintainer may publish the report as a security advisory
and can credit you in it.

## Supported versions

Fixes go into the newest release only. Update to it before reporting, in case
the problem is already fixed.
